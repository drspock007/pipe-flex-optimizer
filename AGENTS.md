- All four modes (Fixed L, Find h, Find L, Min. supports) support free/restrained, with/without ground. Restrained uses its own coupled Hermite/geometric-stiffness solver and combined-stress criterion; never substitute a free solution.
- The exactly flat case (hv = hl = groundZ = 0) uses ground-flat.ts analytically in both axial modes: zero deformation/stress/N, distributed reaction p = q, no mesh or convergence claim. Nodal contact can encounter precision/convergence difficulties; this is not a universal claim that meshes never converge. Trigger by exact equality only. Unrepresentable derived output must return numerical-failure, not fall back to a mesh.
- Free ground fixed-L first tries ground-fast.ts, accepting the exact no-ground solution only when exact member minima clear the ground by > tolPenetration. Otherwise mesh refinement applies; stop after two consecutive precision-loss levels. Distinguish analytical, exact no-contact and mesh-refinement results.
- Ground/restrained searches share ground-sampler.ts and ground-classify.ts; Find L samples ln L via length-sampling.ts. Coverage is exploratory; failed/uncertain regions remain unresolved. Restrained necessary axial bounds are distinct from free Hcap.
- min-support-orchestrator.ts handles exploratory Min. supports: n = 0..ceiling in order under ONE global budget, with final verification. Restrained reuses its Find L final check and handles n-independent exclusions once. Only a verified n = 0 is currently certified minimal; sampling without a candidate never proves lower counts impossible.

- PDF tables are measured with jsPDF-autotable: keep the heading with the first body row, let oversized tables split, carry the last two rows together when feasible. Never move an oversized table wholesale merely to avoid a widow. Preserve all diagnostic rows, margins, footer and font size; visually inspect every SI/imperial page after layout changes.
